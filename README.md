# WuXu's Library

An AltStore source with emulators, games, jailbreaks, utilities, tweaked apps, free streaming and more, kept up to date.

- **Add the source:** `https://bit.ly/wuxuslibrary`
- **Website** (one-tap links and the full app list): https://wuxu1.github.io/
- **Discord** (requests, support, feedback and sideloading chat): https://discord.gg/nKXsSdbEDc

## How to add it

Copy the source link above, then in your app add a source and paste it. It works with AltStore, SideStore, Scarlet, TrollApps, Krava Signer and other signing apps that accept AltStore sources. The Discord server has install guides for each one.

## What is in this repository

- `wuxu-complete.json`: the source itself.
- `wuxu-complete-plus.json`, `wuxu-complete-scarlet.json`: generated copies, kept so older links still work (everything is now in the one source).
- `frontend/`: the website, built and deployed to GitHub Pages.

Apps are released as assets of the `Latest` release.
